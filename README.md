# NMR
GitHub repository for Nuclear Magnetic Resonance (NMR) data and related information associated with physical chemistry 'cloud' laboratory (ASU CHM 343).  There are several NMR instruments at ASU, but most of the data is collected on either a 400 MHz or 500 MHz Bruker NMR spectrometer.  Both of these Bruker NMR instruments are setup for automated NMR and remote access and data acquisition.   ASU has further developed remote, automated NMR and 'cloud' NMR data storage through [spintropy.com](https://spintropy.com/).  All local and remote NMR data collected at ASU is automatically logged and stored at Spintropy.Com and all users need to register for a spintropy.com account.  For students in pchem 'cloud' lab (CHM 343), we have a ASU_CHM343 spintropy.com account that all students can use to access all NMR data collected for this ASU Online lab course.  The password for the ASU_CHM343 account on spintropy.com is provided to students registered in the course on the official Canvas course LMS site.  Publicly accessible copies of the NMR data collected and stored on spintropy.com, are also uploaded in the Data subfolder of this CHM343 > NMR (> Data) github account.  The reason for this is that all the files stored on GitHub are open and publicly available, and will be available to anyone.
