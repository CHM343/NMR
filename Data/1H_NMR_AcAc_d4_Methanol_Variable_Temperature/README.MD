# Bruker 400 MHz 1H NMR Data - AcAc in d4-Methanol with TMS

Variable temperature 1H NMR spectral data saved in text (tsv) and jcamp (jdx) formatted files.  NMR data was collected and processed on a 400 MHz Bruker NMR and reference using TMS.
The sample was a 3 mm flamesealed NMR tube and the temperature was changed from set point values of 289K to 303K to 308K to 313K to 318K.  It takes ~ 4 min to increase the temperature
to each set point and this is followed by a 1 scan data collect with a 60 sec delay time, and repeated 4 times to observe any kinetics (so, 4, 6, 8 and 10 min). 
d4-Methanol can also be used to calibrate the variable temperature NMR and it was found that the set point temperatures deviate significantly from the temperature determined from 
d4-Methanol.  The actual sample temperature was calculated to be 298K, 306K, 314K, 321K and 327K +/- 1K.   This can be validate using the spectral data files.
